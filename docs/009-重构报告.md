## 主要改动

- **基线**：官方引擎整体 vendor，保留 Eval 两层、Policy 版本化与历史、Thread/Subscription/Correlation、每工单独立 session + 目录、六页签面板、管理 API。
- **删除**：`lib/single-session.js`、dispatcher preset、登记胶囊、`delegate/roles/role-notes/child-tickets` 等自研编排层，以及它们的测试与文档。
- **QQ**：
  - `qq-trigger.ts` 把 OneBot v11 事件和 roost-host 帧归一成 Trigger（确定性 id、thread、actor、addressed、reply address）；
  - `qq.ts` 是 Source kind（设置、scope、Policy 行、health、environment）；
  - `qq-loops.ts` 按 mode 建连接、重连退避、串行 receive；
  - `qq-channel.ts` 回写原群/私聊，连接不在时抛错让 Outbox 重试；
  - `qq-onebot.ts`：HTTP 动作（业务错误不重试，仅网关不可达重试）+ Universal WebSocket；
  - `qq-roost.ts`：`/rpc` 与 SSE（带 since 续传、心跳忽略）。
- **Windows**：绝对路径正则认盘符；shim 生成 `.cmd`；命令解析走 PATHEXT；worker probe 不再依赖 POSIX `env`；prepare 命令用 `pwsh -Command`；POSIX-only 的 36 条测试按平台跳过。

## 2 验证细节

- 飞书 token：首次取 `tenant_access_token` 并缓存；401 或业务码 `99991663` 时清缓存重试一次。
- 过滤：非文本、`sender_type=app`（机器人自己）、无 @（`requireMention=true` 时）、作者白名单外、`create_time <= since`。
- 回写：`send(thread='chat:<id>')` → `POST /open-apis/im/v1/messages?receive_id_type=chat_id`；`confirmWrites=false` 时抛错。
- `ack()`：飞书没有 ack 语义，返回 `{skipped:true}`，靠水位去重。

## 3 限制 / 待补

1. **真实飞书未验**：缺 app 凭证；`start_time` 的单位（秒/毫秒）按公开文档用秒，等真凭证到位后先单群验证一次（R6）。
2. 飞书事件长连接不做（计划只做轮询）。
3. 私聊（p2p）场景需把 `requireMention` 设 false；当前按群聊默认真。
4. 评论/回复线程未做（飞书 `thread` 只到 chat 级）。

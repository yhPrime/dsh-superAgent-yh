## 1 交付

- `client.js`：DSH 应用内客户端模块（`dsh.client`）
  - 左栏 `sidebar.panellist` 图标（id `dsh-superagent-yh`）→ `main` 主面板
  - 右栏页签类型（`sidebarRightTabs.register`，kind `dsh-superagent-yh`）+ `sidebar.right.pane.tab` 正文/标题
  - 关闭：主面板「关闭」→ `layout.selectPanel(null)`；右页签原生关闭 + 体内「关闭」→ `tab.actions.close()`
  - 功能：三态/源状态/工单表；重试、取消、打开会话、看日志；dryRun/主线/轮询/preset + GitHub/飞书/QQ 源配置

- `package.json`：`0.3.0`，`dsh.client`（web/immediately/inject），`./client` 导出，打包含 `client.js`

## 3 未验 / 需要重启

1. **客户端 UI 尚未在真实页面加载**：`dsh.client` 是新模块，装好后必须重启一次 DSH 才会进入客户端模块图。host 路由与 `superagent_status` 不受影响。
2. 左/右入口的**视觉与交互**（图标位置、页签外观、关闭按钮手感）未做浏览器走查。
3. 右栏依赖 better-sidebar 的 `sidebarRightTabs`；未装时自动跳过（左栏仍可用）。
4. 源配置表单把 token 写入 profile 配置（明文，沿用现有配置方式）；表单只显示「已配置/未配置」，不回显明文。

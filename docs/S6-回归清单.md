# S6 控制台回归清单（一条命令 / 人工前置）

> 版本：v1.0 · 状态：定稿（2026-11-26） · 权威范围：控制台重构 S6「测试与回归」的可执行步骤
> 计划书：`docs/控制台重构计划书-v1.0.md` §09 S6；本清单只描述**怎么跑**，结论写在 `docs/S6-第二轮测试报告.md`。

## 0. 一条命令

```bash
node test/tools/console-regression.mjs      # 退出码 0 = 全绿；非 0 = 有一步红了
```

不需要先启动 DSH，不需要开端口，不需要装依赖（只用 Node 内置 `node:test` / `node:http` / 全局 `fetch`）。
耗时约 1~2 秒。四步依次是：

| 步骤 | 做什么 | 红了意味着 |
| --- | --- | --- |
| 1 | `test/tools/console-i18n-check.mjs`：zh/en 键集零差集、无空值、无未使用键 | 新文案只加了一边，或 key 写了但没在 client.js 用到 |
| 2 | `node --test` 控制台 7 个测试文件（三态/视图/S4/S5/数据层/字典/冒烟） | 视图接线、数据层、三态断言回归 |
| 3 | 进程内起 `test/tools/console-mock-server.mjs`，跑 `verify-v210.mjs --console` 期望退出码 0 | 五路由冒烟断言或 mock 形状漂移 |
| 4 | 对临时关闭的端口跑 `verify-v210.mjs --console`，期望 5 秒内退出码 2 且输出含「无法连接」 | 无服务时又变成挂死/未捕获异常 |

## 1. 组件与前置条件

### 1.1 mock 宿主（无需 DSH）

`node test/tools/console-mock-server.mjs [port]` 直接运行会打印 `MOCK_READY <port>` 并常驻；`port` 省略则系统分配。
也可 `import { startMockServer } from './test/tools/console-mock-server.mjs'` 拿 `{ port, close }`。
它只实现冒烟用到的 5 个路由和最小 JSON 形状，不写盘、不发外网请求、不返回任何明文密钥。

### 1.2 五路由冒烟脚本

```bash
node test/tools/verify-v210.mjs [baseUrl] --console
```

- `baseUrl` 默认 `http://127.0.0.1:54196`，API 前缀 `/dsh-superagent-yh`。
- **真机前置**：先启动 DSH，端口以本机 DSH 启动日志为准（默认不是固定的，别硬编码）。
- **退出码**：`0` 全通过 · `1` 断言失败 · `2` 连不上（脚本在首次 `/status` 就停，打印「FAIL 无法连接」和前置说明，不会继续刷 25 条失败）。
- **注意**：冒烟含写请求（`POST /settings` 存一次合法 preset、`POST /action` 空 payload/缺 role）。**不要对正在给别人用的宿主直接跑**；真机验收请在重启后、无人使用时跑。

### 1.3 真机人工步骤（S6 不代替）

1. 启动 DSH，从启动日志拿到端口 `P`。
2. `node test/tools/verify-v210.mjs http://127.0.0.1:P --console`，期望 25/25 通过、退出码 0。
3. 打开控制台，按 `docs/S0-待验清单.md` 做视觉/读屏项（截图基线、G1 窗口计数、窄栏不溢出、dirty 提示、禁用态观感）。

## 2. 变更时怎么维护

- 新增/删除一个 `EmptyState` 复用点 → 更新 `test/unit/console-states.test.js` 的计数断言（当前恒为 8）。
- 新增/修改一处 `disabled:` → 更新同文件的 5 处禁用点表与计数断言。
- 新增页签或视图 → 同时补 `console-view.test.js` 的 5 视图/页签断言。
- 新增 DICT 键 → 必须 zh/en 成对，否则第 1 步必红。
- S5b 落地 `humanizeError()` 后 → 把 `console-states.test.js` 里那条 `todo` 换成真断言（规格已写在注释里）。

## 0 一句话

把现有独立网页升级为 DSH 应用内控制台：**左侧栏图标**打开主面板（工单三态、源状态、操作、源配置），**右侧栏**提供一个同源的紧凑页签。

## 1 现状

- `lib/panel.js` 只注册 `/dsh-superagent-yh` 独立页 + `/status` + 三字段设置；无 `dsh.client`，DSH 应用内没有入口。
- 能看：三态计数、按源分组工单、最后错误、dryRun/主线/轮询三个设置。
- 不能：配置源（GitHub/飞书/QQ）、重试/取消工单、打开 worker 会话、看工单日志。

## 2 范围（A+B）

**A 应用内入口**：

- 左：`sidebar.panellist` 图标（id `dsh-superagent-yh`），点击 `ctx.layout.selectPanel('dsh-superagent-yh')` 打开主面板（`main` keyed slot）；主面板顶部有**关闭**按钮（`selectPanel(null)` 返回会话）。
- 右：注册右栏页签类型（`sidebarRightTabs.register`，kind `dsh-superagent-yh`）+ `sidebar.right.pane.tab` 正文；页签用原生的关闭按钮，正文顶部再给一个**关闭**按钮（`tab.actions.close()`）；better-sidebar 不在时静默跳过（左侧仍可用）。

**B 完整控制台**：

- 工单表：状态、标题、attempts、最后错误、问题；操作：**重试**（failed/queued → queued）、**取消**（running/waiting → cancel 会话 + failed）、**打开会话**（`uiWorkspace.openSession`）、**查看日志**（GET 尾部 200 行）。
- 源配置表单：GitHub（enabled/repo/labels/authors/token/apiBase/confirmWrites）、飞书（enabled/appId/appSecret/chatIds/requireMention/confirmWrites）、QQ（enabled/mode + personal 的 http/ws/selfId 或 official 的 host/port/token）；经 `configEditor` 写回 profile 配置（插件会重载）。
- 配置回显：`/status` 返回脱敏后的 config（token 只回 `hasToken`，不回明文）。

## 3 接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/dsh-superagent-yh/status` | 状态 + 脱敏 config（原有，扩展 config 字段） |
| GET | `/dsh-superagent-yh/log?ticketId=` | 工单日志尾部（≤200 行，脱敏） |
| POST | `/dsh-superagent-yh/action` | `{ticketId, action: retry|cancel}`；Origin 校验 |
| POST | `/dsh-superagent-yh/settings` | 顶字段 + `sources` 白名单深合并；Origin 校验 |

- 所有 POST 校验 `Origin === webServer.getOrigin()`，请求体 ≤ 32KB。
- 设置只接受白名单键；token 为空表示保持原值，不覆盖。
- 重试不新建 worktree：复用同一 ticket 的 worktree/session，重新入队。

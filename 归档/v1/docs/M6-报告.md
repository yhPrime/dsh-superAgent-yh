## 3 本轮修到的真问题

1. **worker preset 启动竞态**：宿主刚启动时 preset 可能未注册完，`create` 会建出没有 loop 的会话，`wait` 立即 idle → 误判失败。修法：首轮延迟 `startupDelayMs`（默认 5s）+ 建会话前 `agentPresets.resolve()` 校验 + 无 assistant 消息时重投一次 mandate。
2. **create 可能返回不同 sessionId**：以返回值为准并回写 ticket，避免后续 resolve 错会话。
3. **面板设置写错行**：`configEditor.entries()` 的 id 带 `include:` 前缀，改成去前缀精确匹配，找不到 404 并列出 entries，不再猜。

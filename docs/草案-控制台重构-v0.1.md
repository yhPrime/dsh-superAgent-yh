## 0 摘要

现在的控制台是**一个 892 行的浏览器单文件**里的**一个 394 行的 `Console` 组件**（`client.js:411-804`），左栏、右栏、会话内任务板、输入区按钮各挂一处，数据靠 **3 套独立的 5 秒轮询**，视觉靠一份内联 CSS 加两份组件内 CSS。它能用，但结构、轮询、文案、窄栏显示和可测性都有欠账；四页签与任务板的真实视觉从 M5 起就**从未走过浏览器走查**。

本草案建议：**选项 B——在 `client.js` 单文件内做“数据层 / 视图层”分层 + 轮询收敛 + 视觉修正**，不新增依赖、不改宿主契约、不建构建链；先交 S0–S3 可自动验证的结构收益，再按拍板项做 S4–S6 的视觉与交互修正。选项 C（拆多文件/前端工程）本期不做。

## 1 现状诊断

### 1.1 入口与页面结构

控制台有 5 个呈现面，全部从同一个 `client.js` 模块注册：

| # | 入口 | 注册位置 | 渲染 | 内容 |
|---|---|---|---|---|
| 1 | 左栏图标 `sidebar.panellist` → `main` 主面板 | `client.js:842-848`、`client.js:836-840` | `MainPanel`（`client.js:823-825`）→ `Console compact=false` | 四页签完整控制台 |
| 2 | 右栏页签 `sidebarRightTabs.register` + `sidebar.right.pane.tab` | `client.js:867-888` | `RightBody`（`client.js:815-821`）→ `Console compact=true` | 只有「概览 / 工单」两页签（`client.js:521`） |
| 3 | 会话头任务板 | `client.js:851-856` | `SessionBoard`（`client.js:363-409`） | 本会话最近 8 条工单（`client.js:384`） |
| 4 | 输入区登记按钮 | `client.js:859-865` | `SingleSessionPill`（`client.js:298-341`） | 点亮即登记本工作区单会话 |
| 5 | 独立只读页 `GET /dsh-superagent-yh` | `lib/panel.js:495-500`、`lib/panel.js:337-356` | `PAGE` 字符串模板（`lib/panel.js:12-60`） | 另一套 HTML/CSS + 工单表 + 3 个设置项 |

四页签（`client.js:11`、`client.js:795-799`）：

- **概览**（`client.js:566-624`）：5 张统计卡（点卡切到工单并过滤，`client.js:549-556`）→ 工作空间卡（上下文条 / 上次压缩 / 立即压缩 / 打开会话 / 解除单会话，`client.js:569-595`）→ 源健康 → 最近 10 条活动。
- **工单**（`client.js:634-686`）：状态 chips + 搜索 + 6 列表格（工单 / 来源 / 状态 / 尝试 / 最后错误 / 操作，`client.js:648-676`）+ 行内日志（`client.js:677-683`）。
- **源**（`client.js:688-744`）：GitHub / 飞书 / QQ 三张源卡与字段。
- **设置**（`client.js:746-778`）：基础、单会话、源配置，底部 sticky 保存条（`client.js:780-786`）。

头部（`client.js:523-547`）在一行里放：标题+副标题、live 点（版本+dryRun）、单会话胶囊开关、刷新、右栏/完整控制台、关闭。CSS `.syh-head` 是 `display:flex` 且**没有 `flex-wrap`**（`client.js:195`），按钮又 `white-space:nowrap`（`client.js:202`）。

### 1.2 数据流

```
宿主 state.json（lib/store.js:17-28 / 109-148）
  └─ lib/panel.js 路由
       GET /status（lib/panel.js:290-322）
         ├─ renderPayload(config/tickets/stats/dryRun/version)
         ├─ singleSession.snapshot()（lib/single-session.js:410-415）
         │    └─ list() + 每个已登记工作区 inspect()（token 计量）
         └─ tickets.slice(-100)（lib/panel.js:320）
       GET /single?sessionId=（lib/panel.js:324-335 → stateOf，lib/single-session.js:419-435）
       GET /log?ticketId=（lib/panel.js:358-367，尾部 200 行 + redact）
       POST /action（lib/panel.js:369-458：purge-intakes / register|unregister|delete-single / compact / retry / cancel）
       POST /settings（lib/panel.js:460-493：Origin 校验、32KB、白名单 mergeSettings）
```

浏览器侧（全部同源 `fetch`，无 WebSocket/事件总线）：

- `useStatus` 挂载即拉 `/status`，之后每 5 秒一次（`client.js:99-118`）。
- 任务板自己拉 `/status?sessionId=`，每 5 秒（`client.js:367-383`）。
- 输入区按钮拉 `/single?sessionId=`，每 5 秒（`client.js:303-317`）。
- 操作统一走 `post()`（`client.js:121-130`）；`/action`、`/settings` 成功后调 `reload()`（`client.js:455-466`）。
- UI 本地状态只有 `Console` 的 10 个 `useState`（`client.js:414-422`）：tab / form / msg / error / log / filter / query / busySession / singleBusy；**不落盘**，`lib/store.js` 也没有 UI 状态（`lib/store.js:17-28`）。

宿主契约（当前实际使用，不能动）：`slots`、`layout.selectPanel`/`selectPanel(null)`（`client.js:401/544/824`）、`locale`、`uiWorkspace.openSession`（`client.js:500-504`、`client.js:832-834`）、`sidebarRight.openTab`（`client.js:513-517`）、右栏 `tab.actions.close()`（`client.js:817-818`）。路由全部小写，注册在 `lib/panel.js:495-500`。

### 1.4 约束（决定方案边界）

1. **单文件入口、无构建链**：`client.js` 通过 `window.__ModuleLoader__.load({ factory(require) {...} })` 加载（`client.js:3-6`），`require` 是宿主模块表，不能相对 import 本地文件；`package.json:11` 的 `exports["./client"]` 直接指向 `client.js`，`dsh.client` 只声明平台/注入（`package.json:19-27`）。要拆多文件，必须加构建产物或改宿主 loader，两者都超出本次。
2. **客户端改动必须重启 DSH 才生效**（`子计划书-M5-控制台.md` R12；`项目信息.md` 关键坑）。左/右/任务板/按钮都只在启动时注册一次。
3. **面板路由全小写**（`项目信息.md`；`lib/panel.js:495-500`）：`/dsh-superagent-yh`、`/status`、`/single`、`/log`、`/action`、`/settings`，大写会 404。本次不改名。
4. **宿主 primitives 只能按已用到的判断**：slots/layout/locale/uiWorkspace/sidebarRightTabs/sidebarRight；视觉只有 `--dsw-alias-*` CSS 变量。宿主 asar 的声明文件在本机读不到（`resources\app.asar` 是单个文件，`app.asar.unpacked\dsh\node_modules\@deepseek-ai` 只有 libreoffice-kit），**不押注未证实的按钮/表格组件**。
5. **项目硬规则**：能复用就复用、不新造 UI 组件库、不新造轮询调度器（`计划书.md` §3，第 73 行）。因此本草案的“轮询收敛”只是把现有 3 个 `setInterval` 合成 1 个，不引入调度框架/新依赖。
6. **状态存储无 UI 态**：`lib/store.js:17-28` 只有 watermark/tickets/sourceStatus/singleSession/lastError；本次不扩 schema。

## 2 目标与非目标

### 2.1 目标（可验收）

| 编号 | 目标 | 判据 |
|---|---|---|
| G1 | 一处数据源、一份轮询 | 同一页面所有控制台消费者共享 `status`；主面板与右栏同开时 `/status` 每 5 秒最多 1 次；任务板不再单独打 `/status?sessionId=`；`/single` 只在按钮挂载时按资源轮询；页面隐藏时暂停；连续失败退避。 |
| G2 | 视图与数据解耦、可测 | 四个视图移出 `Console`，成为显式 props 的组件；调度器/过滤/i18n 有单测；`Console` 回落到组合与交互，目标 ≤ 250 行。 |
| G3 | 窄栏可读、视觉一致 | 右栏（约 320–380px）无横向滚动；头部会换行或收纳；工单在窄栏有明确的降级呈现；间距/字号/状态色统一走现有 alias token。 |
| G4 | 文案完整 | zh/en 的“代码使用键”与“DICT 定义键”零差集；新增键成对出现。 |
| G5 | 状态不误导、不静默丢 | 未保存修改在切页签/关闭时有提示；`autoCreate` 不再以可用开关出现；已废弃配置有说明。 |
| G6 | 可访问性基线 | 所有交互控件可 Tab/Enter；任务板行可键盘触发；异步提示有 `aria-live`；不再用 `window.alert`。 |
| G7 | 契约零破坏 | 路由、slot 名、请求/响应字段、Origin/大小校验、token 掩码均不变；不新增 npm 依赖、不新增构建链。 |

### 2.2 非目标（明确不做）

- 不改源协议、触发源（GitHub/飞书/QQ）、水位/去重/回写。
- 不改主线 relay 三条消息、执行器、子智能体、单会话状态机与 preset。
- 不改宿主 slot 契约、路由名、鉴权/Origin 校验、token 存储方式。
- 不引入 React 之外的 UI 库、图标库、状态库、CSS 框架；不新建前端构建链（选项 C 才需要，本草案否掉）。
- 不改任务板与输入区按钮的挂载位置；形态是否调整见 D6/D7，未拍板前不动。
- 不做移动端适配，只保证桌面窄栏（右栏）与常规宽度。
- 不重写独立只读页；只决定其去留/冻结（D8）。
- 不改配置默认值：`autoCreate` 只处理 UI 呈现（D5），除非拍板选“删键并迁移”。
- 不改执行逻辑、日志格式、测试框架。

## 3 方案选项

### 选项 A：就地精修（最小改动）

- **做法**：保留 `Console` 单组件与现有结构，只补三个 i18n 键、给 `.syh-head` 加 `flex-wrap`、去掉 `autoCreate` 开关、合并 `PILL_CSS`/`BOARD_CSS`/`CSS` 的重复规则。
- **改动面**：`client.js` 约 30–60 行；测试基本不动。
- **代价**：约 0.5–1 人日。
- **风险**：低。
- **复用**：全部现有，宿主 primitives 全沿用。
- **问题**：P1/P2/P7/P10 原样保留；下次做结构还得再动一遍；窄栏表格问题只缓解不解决。

### 选项 B：单文件内分层 + 轮询收敛（推荐）

- **做法**：仍只改 `client.js`（测试另加），在模块内划四层：
  1. **常量/文案/CSS**：`TABS`、`DICT`、一份合并后的 CSS（保留胶囊/任务板类名）。
  2. **数据层**：模块级 `consoleStore`——`status`（全量，供主面板/右栏/任务板共用）与 `single:<sessionId>`（按钮）两种资源；订阅者计数启停一个 5s 定时器；single-flight；错误退避；`document.visibilityState` 暂停；操作后 `refresh('status')`。
  3. **视图层**：`OverviewView`/`TicketsView`/`SourcesView`/`SettingsView` 提为顶层组件，显式接收 `data/t/form/handlers/compact`；`Console` 只留状态与编排。
  4. **注册层**：`apply` 不变（`client.js:827-890`）。
- **附加**：任务板改用共享的全量 `status`，在客户端复刻 `filterTicketsForSession`（`lib/panel.js:132-139`，6 行等价逻辑）做本地过滤，去掉 `/status?sessionId=` 请求；服务端仍保留该参数做兼容。
- **改动面**：`client.js` 主体重构（预估净减 40–100 行）；`test/unit/client-smoke.test.js` 扩展；新增 `test/unit/client-store.test.js`、`test/unit/client-i18n.test.js`、`test/tools/console-i18n-check.mjs`。
- **代价**：约 3–5 人日（含四测与走查）。
- **风险**：中（UI 回归/调度竞态），用 S0 基线 + 分步 commit + 可回滚控制。
- **复用**：宿主 slots/layout/locale/uiWorkspace/sidebarRight、现有 HTTP 契约、`--dsw-alias-*`；无新依赖。
- **可测性**：调度、过滤、文案、注册可单测；视觉仍需人工走查。

### 选项 C：拆独立视图层 / 多文件前端工程

- **做法**：`client/` 目录 + esbuild/tsup 打包成单个 `client.js`；组件化、可选 Storybook；或改宿主 loader 支持相对 import。
- **改动面**：新增构建链、`package.json` scripts、产物入库/发布流程、source map、发布校验；`client.js` 变生成物。
- **代价**：约 5–8 人日起步，之后每次发布都多一步构建。
- **风险**：高。宿主 `dsh.client` 契约未证明支持多文件/ESM 相对导入；构建产物与源码漂移；Junction 源码安装方式下还要保证产物同步；违反“不新造/最简洁”。
- **复用**：可复用宿主 primitives，但收益主要是开发体验，用户可见质量与 B 相同。
- **结论**：本期不做。若未来 `client.js` 超过约 1500 行、或需要主题化/组件跨插件复用，再单独评估。

### 对照

| 维度 | A 就地精修 | B 单文件分层（推荐） | C 构建工程 |
|---|---|---|---|
| 解决 P1/P2 | 否 | 是 | 是 |
| 解决 P7/P10 | 否 | 是 | 是 |
| 新增依赖/构建 | 无 | 无 | 有 |
| 改动集中度 | 极低 | 中（单文件） | 高（多文件+产物） |
| 可自动验证 | 低 | 高（调度/过滤/文案） | 高 |
| 回归风险 | 低 | 中 | 高 |
| 回滚 | 容易 | 容易（单文件 revert） | 难（产物/构建） |
| 粗估 | 0.5–1 人日 | 3–5 人日 | 5–8 人日起 |

## 4 推荐方案与理由

**推荐 B。** 理由按优先级：

1. **约束决定**：`client.js` 是唯一入口、无构建链（§1.4-1）。B 是在现有约束内同时拿到“分层 + 轮询收敛”的最短路径；C 的收益不抵构建与发布成本。
2. **对齐“最简洁最优解”**：0 新依赖、0 新路由、0 新产品文件（只加测试），净效果是删重复轮询与重复样式，而不是加抽象层。
3. **解耦但不碎片化**：数据层/视图层用函数边界分开，仍在同一模块；将来真要拆文件时可以整体平移，不会白做。
4. **复用宿主**：继续用 slots/layout/locale/uiWorkspace/sidebarRight 与 alias token；不押注未证实的宿主组件。
5. **可回滚**：改动集中在 `client.js` + 测试；按步 commit，回滚=revert+重启；不碰 state.json 与路由契约。
6. **渐进交付**：A 的修项是 B 的 S1 子集，先做不浪费；视觉改版（S4–S6）等拍板后单独做，避免“结构+视觉”混在一个不可回滚的大改里。
7. **A 不够**：P2 的重复 snapshot/inspect 与 P1 的巨石组件是当前维护成本的主因，A 解决不了；只做 A 等于把同一笔债留到下次。

### S2 数据层收敛（核心结构步）

- **做什么**：
  1. 在模块内加一个**极小**的 `consoleStore`（不是框架，约 80–120 行）：
     - 资源：`status`（全量 `/status`）、`single:<sessionId>`（`/single`）。
     - `subscribe(resource, listener)` 返回退订；首个订阅启动一个 5s 定时器，最后一个退订停表；`document` 不可用（单测环境）时不启动。
     - single-flight：同一资源有在途请求时复用，不叠发。
     - 连续失败退避：5s → 10s → 20s → 30s 封顶；成功复位。
     - `document.visibilityState === 'hidden'` 时暂停，`visible` 时立即补一次。

### 8.1 白盒（`node --test`）

- **文案**：`DICT.zh`/`DICT.en` 键集合相等；代码 `t('…')` 使用集合 ⊆ 定义集合；反向“定义未使用”只报告不失败（允许预留）。
- **调度**：订阅计数启停；5s 单次；single-flight；错误退避序列；`hidden` 暂停/`visible` 补拉；全部退订后无定时器；`refresh` 合并同 tick。
- **过滤**：客户端复刻 `filterTicketsForSession` 与 `lib/panel.js` 导出函数在 fixture 矩阵上逐例相等（含反斜杠/尾斜杠/大小写/空 session/无工作区）。
- **注册**：`client.js` 的 inject 数组、五个 slot 的 name/key/id/order 与 `client-smoke.test.js` 基线一致；无 better-sidebar 时降级不抛错。
- **结构**：`Console` 行数 ≤ 250；`TABS` 仍为四页签（若 D2 改则更新基线）。
- 证据：测试输出 + 新增测试文件。

### 8.2 黑盒（host HTTP，不启浏览器）

- 路由全小写可访问：`GET /dsh-superagent-yh`、`/status`、`/status?sessionId=`、`/single?sessionId=`、`/log?ticketId=` 均 200/预期错误码；大写路径 404。
- `/status` 字段契约：`config`（含 version、token 掩码）、`singleSession`、`tickets`（≤100，含 mode/workspace/targetSessionId/childSessionId）、`stats`、`dryRun` 不丢。
- `POST /action`：register/unregister/delete-single/compact/retry/cancel 的正常与 400/404/409 分支；跨源 Origin 403（`lib/panel.js:148-170`、`369-370`）。
- `POST /settings`：白名单合并、非法值 400、32KB 上限、未知键忽略/拒绝；token 不回显。
- 独立页 200 且不含被 D8 移除的写表单/错误文案（按 D8 结论）。
- 证据：扩展 `test/tools/verify-v210.mjs` 或新增 `test/tools/console-blackbox.mjs` 的 curl/fetch 输出。

### 8.3 真实使用模拟（浏览器，人工走查）

- 重启 DSH 后按场景走：
  1. 左栏图标 → 主面板四页签逐个打开；统计卡点击过滤；工单重试/取消/会话/日志；源配置保存；设置保存。
  2. 右栏页签打开→关闭→再打开；主面板与右栏同开，观察 Network：`/status` 每 5 秒 1 次、`/single` 1 次，无重复突发。
  3. 某会话内任务板：有工单时显示最近 8 条，点击行为符合 D6；无工单时不占位（或按 D6）。
  4. 输入区按钮：未登记→点亮→成功；已登记→禁用并提示“删除请到控制台”；无工作区会话→失败提示可见。
  5. 概览“解除单会话”：确认框与完成文案为正常 zh/en；删除后工作空间卡消失。
  6. 窄栏 320/360/380px：头部不重叠、工单不横向溢出、页签可用。
  7. zh/en 切换；无 better-sidebar 的 profile（或模拟跳过）左栏仍可用。
  8. 独立页（按 D8）：信息正确、无写入口、不承诺假刷新。
- 证据：走查清单勾选 + 截图 + Network 截图；标“需人工走查”。

### 8.4 健壮性

- host 不可用/500/超时/返回非 JSON：控制台显示错误卡不白屏；轮询退避；无未捕获 Promise。
- 数据异常：`tickets` 缺失/非数组、字段缺失、100 条大列表、超长标题/路径/错误、`workspaces` 为空、`singleSession` 关闭。
- 生命周期：快速开关主面板/右栏、切会话、切页签、卸载重挂，定时器不泄漏、无重复请求。
- 浏览器：离线/断网恢复、页面隐藏再回来、慢 3G 模拟（DevTools）。
- 权限/服务缺失：无 `uiWorkspace`、无 `sidebarRight`、无 `better-sidebar` 时按钮/页签的行为与提示。
- 证据：单测 fixture + DevTools 手工场景记录。

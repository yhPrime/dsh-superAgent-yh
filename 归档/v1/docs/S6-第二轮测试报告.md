## 4. `disabled` 现状只读探测（S6 不实现，只登记）

**结论：没有统一 `disabled` 语义。**全客户区只有 5 处 `disabled:`，都是「请求在途 / 前置缺失」的局部条件；没有 `aria-disabled`、没有 `disabledReason`、没有「为什么禁用」的统一文案，禁用态的说明只靠 `title`/`aria-label` 个别补。

| 位置 | 条件 | 语义 |
| --- | --- | --- |
| `client.js:518` 登记按钮 `SingleSessionPill` | `busy \|\| !sessionId` | 登记请求在途，或当前会话没有可登记的 sessionId（注释与 `title` 会说明工作区归属） |
| `client.js:671` 头部单会话开关 | `singleBusy` | 切换请求在途 |
| `client.js:710` 概览「立即压缩」 | `busySession === workspace.sessionId` | 该行压缩在途，按钮文案同时变「压缩中…」 |
| `client.js:711` 概览「删除单会话」 | `busySession === workspace.sessionId` | 该行删除在途 |
| `client.js:865` 保存按钮 `SaveBar` | `!form` | 表单未加载（无内容可存） |

视觉降级只有 CSS：`.syh-btn:disabled{opacity:.5;cursor:default}`（`:364`）、`.sysi:disabled{cursor:default;opacity:.7}`（`:421`）、`.sysi:hover:not(:disabled)`（`:420`，禁用后不再有 hover 反馈）。

**建议（S7 或后续）**：定义一处 `disabledReason(model) → { disabled, reasonKey }`，统一三件事：①按钮 `title` + `aria-label` 带理由 ②需要时 `aria-disabled`（保留键盘可达的禁用按钮）③DICT 增加 `disabled.*` 文案（zh/en 成对，自动进 i18n 门）。检查点：5 处逐个迁移，`console-states.test.js` 的计数断言同步调整。
